# API 명세서 — SOMA 요가 인강 플랫폼

> Base URL: `http://localhost:4000/api`
> 인증이 필요한 API는 요청 헤더에 `Authorization: Bearer <token>` 포함

---

## 1. 인증 (`/auth`)

### POST /auth/signup — 회원가입

**Request Body**
```json
{
  "name": "홍길동",
  "nickname": "요가러버",
  "email": "user@example.com",
  "password": "password123",
  "role": "user"
}
```
> `role`: `"user"` (학생) 또는 `"instructor"` (강사). 기본값 `"user"`.

**Response 201**
```json
{
  "success": true,
  "token": "eyJhbGci...",
  "user": { "id": 1, "name": "홍길동", "nickname": "요가러버", "email": "user@example.com", "role": "user" }
}
```

---

### POST /auth/login — 로그인

**Request Body**
```json
{ "email": "user@example.com", "password": "password123" }
```

**Response 200**
```json
{
  "success": true,
  "token": "eyJhbGci...",
  "user": { "id": 1, "name": "홍길동", "nickname": "요가러버", "email": "user@example.com", "role": "user" }
}
```

---

### GET /auth/me — 내 정보 조회 🔒

**Response 200**
```json
{
  "success": true,
  "data": { "id": 1, "name": "홍길동", "nickname": "요가러버", "email": "user@example.com", "role": "user" }
}
```

## 2. 강의 (`/courses`)

### GET /courses — 강의 목록

**Query Parameters**

| 파라미터 | 타입 | 설명 |
|---------|------|------|
| level | string | 입문 / 중급 / 심화 |
| is_live | boolean | true = 라이브만 |
| search | string | 제목 부분 일치 |
| page | number | 페이지 번호 (기본 1) |
| limit | number | 페이지당 개수 (기본 12) |

**Response 200**
```json
{
  "success": true,
  "data": [
    {
      "id": 1, "title": "아침을 여는 하타 요가", "level": "입문",
      "lecture_count": 10, "total_hours": 4.5,
      "price": 89000, "is_live": 1,
      "instructor_name": "김소라", "avg_rating": 4.9, "enrollment_count": 3247
    }
  ],
  "pagination": { "total": 6, "page": 1, "limit": 12, "totalPages": 1 }
}
```

---

### GET /courses/:id — 강의 상세

**Response 200**
```json
{
  "success": true,
  "data": {
    "id": 1, "title": "아침을 여는 하타 요가",
    "instructor_name": "김소라", "instructor_bio": "...", "instructor_avatar": null,
    "curriculum": {
      "1": [{ "id": 1, "week": 1, "sort_order": 1, "title": "오리엔테이션", "duration_sec": 480, "is_preview": 1, "video_url": "0Ad4j-qlG04" }]
    },
    "reviews": [{ "id": 1, "reviewer_nickname": "박지은", "rating": 5, "content": "좋아요!", "created_at": "2025-03-10" }],
    "isEnrolled": false,
    "isWishlisted": false
  }
}
```

## 3. 수강 신청 (`/enrollments`) 🔒

### POST /enrollments/:courseId — 수강 신청
**Response 201**
```json
{ "success": true, "data": { "enrollmentId": 1 } }
```

### GET /enrollments — 내 수강 목록
**Response 200**
```json
{
  "success": true,
  "data": [
    { "enrollment_id": 1, "course_id": 1, "title": "아침을 여는 하타 요가",
      "instructor_name": "김소라", "lecture_count": 10,
      "completed_lectures": 3, "progress_rate": 30 }
  ]
}
```

### DELETE /enrollments/:courseId — 수강 취소
**Response 200**
```json
{ "success": true, "message": "수강이 취소되었습니다." }
```

### POST /enrollments/:courseId/wishlist — 찜 토글
**Response 200**
```json
{ "success": true, "data": { "wishlisted": true } }
```

## 9. 파일 업로드 (`/upload`) 🔒

### POST /upload/thumbnail — 썸네일 업로드

**Request**: `multipart/form-data`, 필드명 `file` (이미지, 최대 5MB)

**Response 200**
```json
{ "success": true, "data": { "url": "/uploads/1712345678-abc123.jpg" } }
```

## 공통 에러 응답

| 상태 코드 | 설명 |
|---------|------|
| 400 | 잘못된 요청 (필수 필드 누락, 유효성 실패) |
| 401 | 인증 토큰 없음 또는 만료 |
| 403 | 권한 없음 (타인 리소스 접근) |
| 404 | 리소스 없음 |
| 409 | 중복 (이미 수강 신청, 이미 후기 작성 등) |
| 500 | 서버 내부 오류 |

```json
{ "success": false, "message": "에러 메시지" }
```
