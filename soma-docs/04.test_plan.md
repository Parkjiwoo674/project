# 테스트 계획

## 실행 환경

- 백엔드: REST API 직접 호출 테스트 (Postman 또는 curl)
- 프론트엔드: 브라우저에서 수동 기능 테스트
- TypeScript: `getDiagnostics` 로 타입 에러 0건 확인 (매 Phase)

---

## Phase 1. 인증

### T-AUTH-01. 회원가입
- [ ] 정상 가입 → 201, token + user 반환
- [ ] 이메일 중복 → 409 에러
- [ ] 비밀번호 8자 미만 → 400 에러
- [ ] 필수 필드 누락 → 400 에러
- [ ] role = instructor 가입 → instructors 테이블에 자동 등록 확인
- [ ] role = admin 가입 시도 → 400 에러 (허용 안 함)

### T-AUTH-02. 로그인
- [ ] 정상 로그인 → 200, token + user(role 포함) 반환
- [ ] 존재하지 않는 이메일 → 401 에러
- [ ] 비밀번호 불일치 → 401 에러

### T-AUTH-03. 토큰 복원
- [ ] 로그인 후 새로고침 → 로그인 상태 유지
- [ ] 만료된 토큰 → 자동 로그아웃

## Phase 2. 강의 목록 및 상세

### T-COURSE-01. 강의 목록

- [ ] level 필터 → 해당 레벨만 반환
- [ ] is_live 필터 → 라이브 강의만 반환

- [ ] lecture_count가 lectures 테이블 COUNT와 일치하는지 확인

### T-COURSE-03. 미리보기 모달
