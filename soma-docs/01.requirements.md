# 요구사항 명세서 — SOMA 요가 인강 플랫폼

## 1. 개요

요가 강사와 수강생을 연결하는 온라인 인강 플랫폼이다. 강사는 강의를 등록·관리하고, 학생은 강의를 검색·수강 신청·수강할 수 있다. React + TypeScript 프론트엔드와 Node.js + Express 백엔드, MySQL 데이터베이스로 구성된다.

## 2. 사용자 시나리오

### 2.1 학생 — 강의 검색 및 수강 신청
1. 학생이 강의 목록 페이지에 접속한다.
2. 탭(전체/입문/중급/심화/라이브) 또는 검색어로 강의를 필터링한다.
3. 마음에 드는 강의 카드를 클릭해 상세 페이지로 이동한다.
4. 미리보기 버튼을 눌러 30초 샘플 영상을 확인한다.
5. 수강 신청 버튼을 클릭한다 (비로그인 시 로그인 페이지로 이동).
6. 수강 신청이 완료되면 내 수업 페이지에서 확인할 수 있다.

### 2.2 학생 — 강의 수강
1. 내 수업 페이지에서 수강 중인 강의 카드를 클릭한다.
2. 강의 플레이어 페이지로 이동한다.
3. 커리큘럼 사이드바에서 원하는 강의를 선택한다.
4. 유튜브 영상이 재생된다.
5. 재생 위치가 자동 저장되어 다음에 접속 시 이어서 볼 수 있다.
6. 완료 버튼을 누르면 진도율이 올라간다.

### 2.3 학생 — 후기 및 Q&A
1. 수강 중인 강의 상세 페이지에서 후기를 작성한다 (별점 + 텍스트).
2. Q&A 섹션에서 질문을 등록한다.
3. 강사 또는 다른 수강생이 답변을 달 수 있다.

### 2.4 강사 — 강의 등록
1. 강사로 회원가입 후 로그인한다.
2. 내 강의 관리 페이지에서 새 강의 버튼을 클릭한다.
3. 제목, 설명, 레벨, 가격, 기간, 썸네일 이미지를 입력한다.
4. 강의를 저장한 뒤 커리큘럼을 추가한다.
5. 각 강의에 유튜브 링크와 제목, 주차, 재생 시간을 입력한다.
6. 준비가 완료되면 공개 버튼을 눌러 학생에게 노출한다.

## 4. 비기능 요구사항

| ID | 요구사항 |
|----|---------|
| NF-01 | 인증은 JWT 토큰 기반으로 처리한다 |
| NF-02 | 비밀번호는 bcrypt로 해싱하여 저장한다 |
| NF-03 | API는 RESTful 설계를 따른다 |
| NF-04 | 한국어 UI를 기본으로 한다 |
| NF-05 | 강의 수, 총 시간은 DB에서 실시간 집계한다 (고정값 저장 금지) |

## 5. 화면 구성

### 5.1 랜딩 페이지
- 히어로 섹션 (슬로건 + CTA 버튼)
- 특징 소개 섹션
- 인기 강의 3개 (별점 순, 실시간 API)
- 강사 소개 섹션

### 5.2 강의 목록 페이지
- 레벨/라이브 탭 필터
- 검색창
- 강의 카드 그리드 (3열)

### 5.3 강의 상세 페이지
- 강의 정보 헤더 (제목, 강사, 평점, 수강생 수)
- 수강 신청 카드 (미리보기 썸네일, 가격, 찜하기)
- 커리큘럼 섹션
- 후기 섹션 (작성 폼 + 목록)
- Q&A 섹션 (질문 등록 + 아코디언 목록)

### 5.4 강의 플레이어 페이지
- 유튜브 iframe 영상 영역
- 이전/다음 강의 컨트롤 바
- 커리큘럼 사이드바 (시청 위치 표시)

### 5.5 내 수업 페이지
- 수강 중인 강의 카드 그리드
- 진도율 바
- 수강 취소 버튼

### 5.6 찜 목록 페이지
- 찜한 강의 카드 그리드
- 찜 취소 버튼

### 5.7 강사 대시보드
- 내 강의 목록 (좌측)
- 선택된 강의의 커리큘럼 관리 (우측)
- 강의 등록/수정 모달
- 강의 영상 추가/수정 모달

### 5.8 로그인/회원가입 페이지
- 학생/강사 역할 선택 카드
- 이메일, 비밀번호 입력 폼
- 로그인 / 회원가입 탭 전환
